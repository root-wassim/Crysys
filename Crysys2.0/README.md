# Crysys 2.0

Unified Cryptography Engine & Academic Lab.

## Overview
Crysys 2.0 is a complete suite combining:
- A high-performance **C cryptography engine** (compiled to `crysys_cli.exe`)
- A **Python academic crypto lab** for educational demos and advanced algorithms
- A **Flask-based unified web application** featuring Encrypt/Decrypt tools, Academic Crypto Lab, and P2P Secure Chat.

## Quick Start
Run `run.bat` on Windows. It will install requirements, build the C engine, and start the Flask web server.
